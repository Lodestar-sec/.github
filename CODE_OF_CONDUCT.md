# Code of Conduct

Lodestar Security adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as the code of conduct for all repositories, issues, discussions, and other project spaces.

In short: be respectful, assume good intent, give constructive feedback, and keep discussions focused on the work.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the maintainers at **lltuongg@gmail.com**. All reports are reviewed promptly and handled confidentially.

## Enforcement

Maintainers follow the [Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction, warning, temporary ban, and permanent ban, depending on the severity and pattern of behavior.
