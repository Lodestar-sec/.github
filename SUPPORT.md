# Support

| I want to… | Go here |
|---|---|
| Ask a usage question | The repository's **Discussions** tab |
| Report a bug | A new issue using the **Bug report** template |
| Request a feature | A new issue using the **Feature request** template |
| Report a vulnerability | The [security policy](SECURITY.md) — never a public issue |

Please search existing issues and discussions before opening a new one. When reporting a problem, include the product version, your environment, and the exact steps to reproduce.
